# راهنمای راه‌اندازی چت

این پروژه یک چت شبیه واتساپ است: ثبت‌نام با نام و رمز، گفتگوی دونفره و یک گروه عمومی.
تهیه‌کننده: Wahed Sarwary

## ۱) امتحان روی کامپیوتر خودتان
1. Node.js (نسخه ۱۸ یا بالاتر) را از nodejs.org نصب کنید.
2. در پوشه‌ی پروژه این دو دستور را بزنید:
   npm install
   npm start
3. در مرورگر آدرس http://localhost:3000 را باز کنید.

## ۲) گذاشتن روی اینترنت (مثلاً Render)
1. در github.com حساب بسازید، یک مخزن (Repository) جدید بسازید و این چهار فایل را در آن آپلود کنید: server.js و package.json و index.html و README.md (همه کنار هم، بدون پوشه).
2. در render.com ثبت‌نام کنید (می‌توانید با حساب GitHub وارد شوید).
3. گزینه‌ی New و بعد Web Service را بزنید و مخزن‌تان را انتخاب کنید.
4. این مقادیر را بگذارید:
   - Build Command: npm install
   - Start Command: npm start
   - Instance Type: Free
5. Deploy را بزنید. بعد از چند دقیقه یک آدرس مثل https://اسم-شما.onrender.com به شما می‌دهد.
6. همان آدرس را برای دوستانتان بفرستید. هرکس با یک نام و رمز حساب می‌سازد و چت می‌کند.

## نکته‌های مهم
- در پلن رایگان Render، سرور بعد از مدتی بی‌استفاده می‌خوابد و اولین باز کردن لینک چند ثانیه طول می‌کشد.
- پیام‌ها و حساب‌ها در فایل data.json ذخیره می‌شوند. در پلن رایگان این فایل با هر بار راه‌اندازی دوباره‌ی سرور پاک می‌شود. برای ماندگاری باید دیسک دائمی بگیرید یا بعداً چت را به یک دیتابیس وصل کنید.
- رمزها به‌صورت هش‌شده ذخیره می‌شوند، اما این یک نسخه‌ی ساده است: پیام‌ها رمزنگاری سرتاسری ندارند. رمزی که برای جاهای مهم استفاده می‌کنید این‌جا نگذارید.
- شرایط پلن رایگان Render ممکن است تغییر کند؛ قبل از شروع در سایتشان بررسی کنید.
